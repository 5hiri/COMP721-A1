Status Posting System

Report

What special features have you done or attempted in creating the website?

Implemented server-side pagination for the status search results page. When the number of results exceeds a set limit per page (3 rows of 4 items), the results are split across multiple pages.

Added 'Previous' and 'Next' navigation buttons to allow users to browse through the paginated search results.

Added a 'Delete' button for each status displayed in the search results, allowing users to remove specific status entries from the database after confirmation.

Ensured that the status posting form retains user input if server-side validation fails, preventing users from having to re-enter all data.

Included a wildcard search feature: entering '*' in the search bar retrieves all status records from the database.

Which part(s) did you have trouble with?

Initially, I faced difficulties establishing a stable connection to the AUT database server. Troubleshooting the connection parameters and ensuring the credentials were correct took some time.

Implementing the pagination logic correctly, specifically handling the state between page loads (maintaining the current page number and search term while resetting the page for new searches), required careful state management using PHP sessions and URL parameters.

What would you like to do better next time?

I would aim for better time management. Allocating more consistent time throughout the project duration, rather than concentrating the work towards the end, would likely lead to a less stressful process and potentially allow for more features or refinement.

What you have learnt along the way? Did you use any references or resources during this project? If so, please include the sources.

This project provided practical experience in using PHP for server-side web development, including handling form submissions (POST/GET), performing data validation, interacting with a MySQL database (connecting, querying, inserting, deleting results), and managing user state with sessions.

I primarily consulted online documentation and examples, particularly from W3Schools (www.w3schools.com) for PHP syntax and function usage, and the official PHP documentation (www.php.net) for specific function details.
